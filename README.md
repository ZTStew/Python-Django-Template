### Commands:
- Run Server:
   - `python manage.py makemigrations && python manage.py migrate && python manage.py runserver`
- Clear Database Records:
   - `python manage.py flush`
    - Note: will not remove generated files and folders generated by program, only their reference. In order to delete the files or folders, they must be manually deleted.
